# BehindTheWalls

A Roblox game project scaffold for BehindTheWalls.

## Structure

- `src/ServerScriptService/` - server scripts
- `src/StarterPlayer/StarterPlayerScripts/` - client scripts
- `src/ReplicatedStorage/Shared/` - shared modules
- `default.project.json` - Rojo project configuration

## Getting started

1. Open the project in Roblox Studio using Rojo, or sync the folder into a Roblox place.
2. Start with the server bootstrap in `src/ServerScriptService/Main.server.lua`.
3. Add gameplay systems under `src/ReplicatedStorage/Shared/` and `src/StarterPlayer/StarterPlayerScripts/`.

## Notes

This repo is intentionally scaffolded as a clean starting point for the game. Add the actual map, mechanics, and assets as development continues.
